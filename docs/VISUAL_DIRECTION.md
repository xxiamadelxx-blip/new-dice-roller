# Visual direction

## Статус

Текущая сцена — `candidate`. Она прошла авторскую техническую сборку, но не считается утверждённым golden-визуалом до просмотра пользователем.

## Собственная интерпретация moodboard

Пользовательские изображения задали четыре направления, которые реализованы собственной процедурной геометрией WebGL2 и authored CSS-атмосферой. Базовый экран теперь собирается как изометрический 3/4 кадр: отдельный восьмиугольный лоток лежит на столе, а не заменяет его фон.

| Сигнал | Авторское решение в приложении |
| --- | --- |
| тёмные каменные и стеклянные кубики | отдельные локальные die-скины с контрастными гранями и цифрами |
| восьмиугольный лоток с гравировкой | WebGL-лоток с полым высоким бортом, деревянно-металлической кромкой, крепежом, медной бабочкой и звёздами |
| деревянная башня с металлическими деталями | цилиндрическая WebGL-башня с верхней короной, фронтальным каналом и выходной полкой |
| ботанические, ночные и красно-чёрные оттенки | независимые палитры стола, лотка и башни |
| свеча/лампа на столе | процедурная тёплая лампа и янтарный key light в WebGL shader |

Ни один внешний dice-roller runtime, skin asset, компонент или код не копируется. Сцена собирается собственным WebGL2 renderer; прозрачный canvas показывает authored CSS-атмосферу только как фон, а DOM используется для управления и доступных числовых labels поверх реального canvas.

## Правила приёмки

1. Технический QA проверяет наличие и стабильность слоёв, контролов, fixture и QA manifest.
2. Browser smoke проверяет реальные размеры, фокус, навигацию, бросок и восстановление истории.
3. Визуальный candidate просматривается пользователем отдельно.
4. Только после явного одобрения candidate может быть отмечен как approved golden.
