# Ø Arcane Desk — Dice Roller

Greenfield-прототип броска D&D-кубиков от `d4` до `d100`.

## Что уже работает

- типы `d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100`;
- количество кубиков от 1 до 12;
- модификатор от `-99` до `+99`;
- три поверхности сцены: стол, лоток и башня;
- локальный каталог скинов для костей, лотка, башни и фона;
- безопасный `Web Crypto` RNG;
- фиксация результата до запуска CSS-анимации;
- локальная история бросков;
- технический QA-режим по адресу `/?qa=1`.

## Локальный запуск

Проект не требует сборщика или внешних CDN-зависимостей:

```bash
npm test
npm run check
python3 -m http.server 4173
```

После запуска открыть `http://localhost:4173/`.

Для QA открыть `http://localhost:4173/?qa=1`. На странице появится пульт с профилем сцены и fixture `d20 × 3 + 2`, которая должна дать `36`.

## Архитектура

- `src/core.js` — независимая модель броска и нормализация входных данных;
- `src/scene.js` — авторский каталог материалов и процедурный DOM-рендер сцены;
- `src/app.js` — UI, локальное состояние, история и QA bridge;
- `styles.css` — authored CSS-сцена без внешних изображений;
- `assets/visual-manifest.json` — технический manifest candidate-визуала.

## Границы источников

Runtime создан с нуля в этом репозитории. Визуальные материалы, CSS-формы и модель броска не переносятся из сторонних dice-roller проектов. Пользовательские изображения использованы только как moodboard для материалов и атмосферы. Документы разрешённых Visual Lab, Cloud Test Stand и Ø Browser репозиториев использованы только для совместимых QA/evidence-ограничений.

`candidate` не означает художественное утверждение: финальное визуальное одобрение остаётся за пользователем.

## Проверка стендом

Это web-прототип, а не APK. Android Cloud Test Stand не должен выдавать native pass для него; native-проверка появится отдельным этапом только после явного Android wrapper и фиксации точного source SHA и артефакта.
